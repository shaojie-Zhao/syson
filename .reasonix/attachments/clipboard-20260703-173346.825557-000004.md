# 资源管理器模型对象创建机制

> 日期: 2026-07-03 | 分支: feature/combine

## 1. 概述

本文档描述如何在 DoDAF OV-1 View 中创建军标图元时，自动在资源管理器（Explorer Tree）中同步创建对应的 SysML PartUsage 作战概念对象，并完成命名。核心涉及三个步骤：
1. **创建** — `createChild` GraphQL mutation 在指定父节点下创建 PartUsage
2. **映射** — 将 Sirius 对象 ID 转换为 EMF elementId
3. **命名** — REST API 设置 PartUsage 的 `declaredName`

---

## 2. 创建 PartUsage 模型对象

### 2.1 GraphQL Mutation: createChild

直接在 SysML 模型中的 ViewUsage 节点下创建子元素 PartUsage。

**Mutation 签名:**
```graphql
mutation createChild($input: CreateChildInput!) {
  createChild(input: $input) {
    __typename
    ... on CreateChildSuccessPayload { object { id } }
    ... on ErrorPayload { message }
  }
}
```

**Input 参数:**
```typescript
interface CreateChildInput {
  id: string;                         // 操作 UUID (crypto.randomUUID())
  editingContextId: string;           // 当前编辑上下文 ID
  objectId: string;                   // 父节点 ID (ViewUsage 的 targetObjectId)
  childCreationDescriptionId: string; // 子元素类型: "SysMLv2EditService-PartUsage"
}
```

**调用示例 (TypeScript/JavaScript):**
```typescript
// 1. 创建 PartUsage
const CREATE_CHILD = `
  mutation createChild($input: CreateChildInput!) {
    createChild(input: $input) {
      __typename
      ... on CreateChildSuccessPayload { object { id } }
      ... on ErrorPayload { message }
    }
  }`;

const response = await fetch('http://192.168.3.111:8080/api/graphql', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    query: CREATE_CHILD,
    variables: {
      input: {
        id: crypto.randomUUID(),
        editingContextId: "e1e02c47-8370-4e6f-bb45-3b7d654407f9",
        objectId: "16d7819f-f6cc-4879-ae92-805fe095955e",
        childCreationDescriptionId: "SysMLv2EditService-PartUsage",
      },
    },
  }),
});
// 返回: { data: { createChild: { __typename: "CreateChildSuccessPayload", object: { id: "6288491b-..." } } } }
const siriusObjectId = (await response.json()).data.createChild.object.id;
```

**关键参数说明:**

| 参数 | 值 | 说明 |
|------|-----|------|
| `editingContextId` | 动态获取 | 等于 semanticData UUID，从 Workbench props 传入 |
| `objectId` | ViewUsage 的 `targetObjectId` | 需从 `representation_metadata` 表查询获得 |
| `childCreationDescriptionId` | `"SysMLv2EditService-PartUsage"` | 固定值，映射到 `SysMLv2EditService` 的 PartUsage 创建逻辑 |

### 2.2 获取 Parent ID (targetObjectId)

`createChild` 的 `objectId` 需要是 ViewUsage 元素的 EMF ID，该值存储在 `representation_metadata` 表中。

**查询方式1: Express REST API (推荐)**
```
GET /api/targetObjectId/{representationId}
```

**服务端实现 (Express/Node.js):**
```javascript
// server.js
const { Pool } = require('pg');
const pool = new Pool({
  host: 'localhost', port: 5433, database: 'syson-db',
  user: 'dbuser', password: 'dbpwd',
});

app.get('/api/targetObjectId/:representationId', async (req, res) => {
  const result = await pool.query(
    'SELECT target_object_id FROM representation_metadata WHERE id LIKE $1',
    ['%' + req.params.representationId]
  );
  if (result.rows.length > 0 && result.rows[0].target_object_id) {
    res.json({ targetObjectId: result.rows[0].target_object_id });
  } else {
    res.status(404).json({ error: 'Not found' });
  }
});
```

**查询方式2: 直接 SQL**
```sql
SELECT target_object_id
FROM representation_metadata
WHERE id LIKE '%b8d1ba51-b5c1-4f53-83ff-7f261a95c70c';
```

> `representation_metadata.id` 格式为 `{semanticDataId}#{representationId}`

## 3. 重命名 PartUsage

`createChild` 创建的 PartUsage 使用默认名称（通常为空或 "Part"）。需要通过后端 API 设置 `declaredName`。

### 3.1 ID 映射: Sirius Object ID → EMF elementId

`createChild` 返回的 `object.id`（如 `6288491b-ea34-...`）与 EMF 模型的 `elementId`（如 `20af268e-f0d4-...`）是两套不同的 ID。重命名需要 EMF `elementId`，因此需要先做映射。

**映射端点:**
```
GET /api/elementId/{editingContextId}/{objectId}
```

**服务端实现 (Express/Node.js):**
```javascript
app.get('/api/elementId/:editingContextId/:objectId', async (req, res) => {
  const result = await pool.query(
    'SELECT content FROM document WHERE semantic_data_id = $1 AND name LIKE $2',
    [req.params.editingContextId, '%.sysml']
  );
  for (const row of result.rows) {
    const text = typeof row.content === 'string' ? row.content : JSON.stringify(row.content);
    const idMatch = text.match(new RegExp('"id":"' + req.params.objectId + '"[^}]*'));
    if (idMatch) {
      const elemMatch = idMatch[0].match(/"elementId":"([^"]+)"/);
      if (elemMatch) {
        return res.json({ elementId: elemMatch[1] });
      }
    }
  }
  res.status(404).json({ error: 'Not found' });
});
```

**调用示例:**
```typescript
// 2. ID 映射
const mappingRes = await fetch(
  `http://localhost:3100/api/elementId/${editingContextId}/${siriusObjectId}`
);
const { elementId } = await mappingRes.json();
// elementId = "20af268e-f0d4-4ace-8e4b-d82cee734221"
```

### 3.2 重命名端点

**端点:**
```
POST /api/ov1/rename
Content-Type: application/json

{
  "editingContextId": "e1e02c47-8370-4e6f-bb45-3b7d654407f9",
  "elementId": "20af268e-f0d4-4ace-8e4b-d82cee734221",
  "newName": "海军航空兵"
}
```

**服务端实现 (Spring Boot/Java):**
```java
// Ov1ElementRenameController.java
package org.eclipse.syson.application.ov1;

import java.util.Objects;
import org.eclipse.sirius.components.core.api.IEditingContextPersistenceService;
import org.eclipse.sirius.components.core.api.IEditingContextSearchService;
import org.eclipse.sirius.components.core.api.IObjectSearchService;
import org.eclipse.syson.sysml.Element;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class Ov1ElementRenameController {

    private final IEditingContextSearchService editingContextSearchService;
    private final IEditingContextPersistenceService editingContextPersistenceService;
    private final IObjectSearchService objectSearchService;

    public Ov1ElementRenameController(
            IEditingContextSearchService editingContextSearchService,
            IEditingContextPersistenceService editingContextPersistenceService,
            IObjectSearchService objectSearchService) {
        this.editingContextSearchService = Objects.requireNonNull(editingContextSearchService);
        this.editingContextPersistenceService = Objects.requireNonNull(editingContextPersistenceService);
        this.objectSearchService = Objects.requireNonNull(objectSearchService);
    }

    @PostMapping("/api/ov1/rename")
    public ResponseEntity<?> renameElement(@RequestBody RenameRequest request) {
        // 1. 获取当前编辑上下文
        var ctx = this.editingContextSearchService.findById(request.editingContextId());
        if (ctx.isEmpty()) {
            return ResponseEntity.badRequest().body("EditingContext not found");
        }
        var editingContext = ctx.get();

        // 2. 通过 elementId 查找 EMF 元素
        var found = this.objectSearchService.getObject(editingContext, request.elementId())
                .filter(Element.class::isInstance)
                .map(Element.class::cast);

        if (found.isEmpty()) {
            return ResponseEntity.badRequest().body("Element not found: " + request.elementId());
        }

        // 3. 设置 declaredName 并持久化
        var element = found.get();
        element.setDeclaredName(request.newName());
        this.editingContextPersistenceService.persist(null, editingContext);

        return ResponseEntity.ok().build();
    }

    public record RenameRequest(String editingContextId, String elementId, String newName) {}
}
```

**注入的 Sirius Web 服务说明:**

| 接口 | 方法 | 说明 |
|------|------|------|
| `IEditingContextSearchService` | `findById(String)` | 通过 semanticData UUID 查找当前活动的 EditingContext |
| `IObjectSearchService` | `getObject(IEditingContext, String)` | 通过 EMF elementId 查找元素对象 |
| `IEditingContextPersistenceService` | `persist(ICause, IEditingContext)` | 将内存中的 EMF 模型变更持久化到 PostgreSQL |

**调用示例:**
```typescript
// 3. 重命名
await fetch('http://192.168.3.111:8080/api/ov1/rename', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    editingContextId: editingContextId,
    elementId: elementId,      // EMF elementId (来自 ID 映射)
    newName: "海军航空兵",        // 军标名称
  }),
});
```

## 4. 完整调用流程

### 4.1 时序图

### 4.2 完整代码示例 (TypeScript)

```typescript
// Ov1BlankView.tsx — createPartUsage 函数

const PLOTTING_ORIGIN = 'http://localhost:3100';

function callGraphQL(query: string, variables: any): Promise<any> {
  return fetch('http://192.168.3.111:8080/api/graphql', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ query, variables }),
  }).then(r => r.json());
}

const CREATE_CHILD = `
  mutation createChild($input: CreateChildInput!) {
    createChild(input: $input) {
      __typename
      ... on CreateChildSuccessPayload { object { id } }
      ... on ErrorPayload { message }
    }
  }`;

async function createPartUsage(
  editingContextId: string,
  symbolMsg: { _symbolId: string; name: string },
  parentId: string
): Promise<void> {

  // Step 1: 创建 PartUsage
  const result = await callGraphQL(CREATE_CHILD, {
    input: {
      id: crypto.randomUUID(),
      editingContextId,
      objectId: parentId,
      childCreationDescriptionId: 'SysMLv2EditService-PartUsage',
    },
  });

  const obj = result?.data?.createChild?.object;
  if (!obj?.id) {
    console.warn('createChild failed', result);
    return;
  }

  const siriusObjectId: string = obj.id;
  console.log('PartUsage created, Sirius ID:', siriusObjectId);

  if (!symbolMsg.name) return;

  try {
    // Step 2: ID 映射 Sirius object ID → EMF elementId
    const mapRes = await fetch(
      `${PLOTTING_ORIGIN}/api/elementId/${editingContextId}/${siriusObjectId}`
    );
    if (!mapRes.ok) throw new Error('elementId mapping failed');
    const { elementId } = await mapRes.json();

    // Step 3: 重命名
    await fetch('http://192.168.3.111:8080/api/ov1/rename', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ editingContextId, elementId, newName: symbolMsg.name }),
    });

    console.log('PartUsage renamed to:', symbolMsg.name);
  } catch (e) {
    console.warn('rename failed', e);
  }
}

// 调用入口 — 从 postMessage 接收军标信息
// createPartUsage(editingContextId, { _symbolId: "sym-100-1300-...", name: "海军航空兵" }, viewUsageId);
```

## 5. ID 体系

| ID | 示例值 | 存储位置 | 获取方式 |
|----|--------|----------|----------|
| **editingContextId** | `e1e02c47-8370-...` | Workbench props | 前端直接获取 |
| **representationId** | `b8d1ba51-b5c1-...` | Workbench props | 前端直接获取 |
| **targetObjectId** | `16d7819f-f6cc-...` | `representation_metadata.target_object_id` | Express API 查 DB |
| **Sirius object ID** | `6288491b-ea34-...` | `createChild` 返回值 | GraphQL 响应 |
| **EMF elementId** | `20af268e-f0d4-...` | `document.content` JSON 中 | Express API 查 DB 映射 |
| **_symbolId** | `sym-100-1300-...` | 内存 | 军标属性计算 |

**ID 转换链:**
```
representationId  ──DB查询──→  targetObjectId   (createChild 的 parent)
createChild  ──返回──→  Sirius object ID  ──DB映射──→  EMF elementId  (rename 的参数)
```
