## 一、整体表格基础样式
整体为标准表格，表头深蓝色背景、白色字体；表格内容行使用浅米白色底色，单元格白色内边框分隔，布局规整。

## 二、表头合并规则（最关键结构，逐列说明）
表头分两层：顶层大表头、下层细分表头，从左到右共6列：
1. **第1列：顶层单元格「技术和技能领域」**（上下两行合并，纵向跨2行），深蓝色表头、白字
2. **第2列：顶层单元格「技术和技能」**（上下两行合并，纵向跨2行），深蓝色表头、白字
3. **第3-5列顶层合并成一个大单元格：「技术和技能预测」**（横向合并3列）；下方再拆分3个子列，分别是「短期」「中期」「长期」，均为深蓝色表头、白字

表头层级整理：
| 技术和技能领域（纵向合并） | 技术和技能（纵向合并） | 技术和技能预测（横向合并3列） | | |
| ---- | ---- | ---- | ---- | ---- |
| | | 短期 | 中期 | 长期 |

## 三、表格内容区域
表头下方是数据填写区，预留4行空白数据行，所有单元格底色为浅米白，单元格之间保留白色分隔边框；后续支持新增、删除行。

## 四、补充交互、样式可选要求（按需复制）
### 样式细节
1. 表头背景统一深蓝色，文字白色居中；内容行浅米色，文字默认左对齐、可按需设置居中；单元格边框白色。
2. 所有单元格支持手动录入文本；可适配列宽拖拽调整。

### 常用交互（按需选用）
1. 顶部可增设操作按钮：新增行、删除行、导入、导出，适配表格数据维护；
2. 可增加筛选、搜索功能，针对领域、技能、不同周期预测内容检索；
3. 支持单元格批量编辑、复制粘贴，导出Excel保留现有表头合并格式。
